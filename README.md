# Usama Ansar — Portfolio

A fully animated, interactive 3D developer portfolio built with production-level code, scroll-based animations, and real-world best practices.

### Built with React, GSAP, Three.js, Tailwind CSS & Framer Motion

---

## 🚀 Tech Stack

| Technology        | Description                                 |
| ------------------ | -------------------------------------------- |
| **React (Vite)**   | Fast dev server and production bundling      |
| **Tailwind CSS**   | Utility-first styling for components         |
| **GSAP**           | Scroll-triggered animations and transitions  |
| **Framer Motion**  | Scroll-velocity-based marquee animations     |
| **Three.js**       | 3D hero scene powered by React Three Fiber   |
| **Drei**           | Useful helpers for 3D rendering              |

---

## 📁 Features

- 🔥 3D hero section with an animated planet
- 🧩 Smooth slide-in navbar with staggered link animations
- 🎯 Scroll-triggered service summary with horizontal word motion
- 🖼️ Works section with hover previews and live project links
- ✍️ About section with clip-path image reveal and animated text
- 🏁 Scroll-velocity marquee components with Framer Motion
- 💼 Fully responsive and accessible on all screen sizes

---

## 📦 Setup & Installation

```bash
git clone <this-repo-url>
cd Awwwards-Portfolio
npm install
npm run dev
```

> Open http://localhost:5173 in your browser.

---

## 🛠️ Customization

- Update project/service content in `src/constants/index.js`
- Update the 3D hero scene in `src/sections/Hero.jsx` and `src/components/Planet.jsx`
- Update contact info in `src/sections/Contact.jsx` and `src/sections/Navbar.jsx`
- Adjust colors, fonts, and layout via `tailwind.config.js`
